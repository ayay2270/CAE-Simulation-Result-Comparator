# CAE Simulation Result Comparator

An editable CAE result comparison report, based on the selected Organic Field Report concept. Compare a baseline with design variants, see relative improvement, check an engineering reference, and print the report or copy its chart.

Live site: https://ayay2270.github.io/CAE-Simulation-Result-Comparator/

## Usage

Open `index.html` in a browser. Edit result values, design names, the reference, preferred direction, or baseline. Add and remove design variants as needed. Changes remain in the current browser session; reload restores the example. Use Print / Save PDF to keep a report.

## Deployment

This is a standalone static website. GitHub Pages serves the root of the `main` branch. No backend or build step is required. Google Fonts are loaded externally.

The selected report layout and calculation engine are retained. This repository contains only the report and its five required assets; it does not include or modify the existing production application.
